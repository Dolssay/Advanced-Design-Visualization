The repository contains codework for the Advanced Visualization Methods for Design project by IDOPt lab at Virginia tech.

Demo 1: WebViz
Contains a web-based visualization tool for the ensemble data gather from a GT B777 aircraft design. The tool allows users to visualize the performance of the aircraft design based on different input parameters and configurations. It provides an interactive interface for exploring the design space and analyzing the results.

Demo 2: Ensemble Data Generation
Contains scripts to generate ensemble data for the Archer Midnight UAV design. The scripts read a baseline configuration file, modify certain parameters based on input data, and save the configurations to generate a Latin Hypercube Sampling (LHS) of the input parameters and save the samples to a CSV file use as input for the GLEE visualization tool.
